# 한국노동자고용공단 랜딩페이지

비공식 디자인 시안입니다. 실제 기관의 운영 페이지나 신청 서비스가 아닙니다.

## 파일
- index.html: 디자인, 반응형 스타일, 스크롤 효과가 포함된 페이지
- workers.png: AI로 생성한 메인 이미지
- favicon.svg: 사이트 아이콘
- .nojekyll: GitHub Pages 정적 파일 설정

## GitHub Pages에 게시
빈 저장소에 이 폴더의 파일을 올린 뒤 Settings → Pages에서 Deploy from a branch, main, /(root)를 선택합니다.
기존 저장소의 별도 폴더에 추가하는 경우 기존 Pages 설정을 유지하고 해당 폴더 주소로 접속할 수 있습니다.

별도 설치나 빌드 없이 사용할 수 있습니다. 이미지와 아이콘은 index.html과 같은 폴더에 두세요.
